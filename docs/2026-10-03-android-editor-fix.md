# Android .6 외부 입력창 수정 기록

## 증상과 확인한 원인

앱 내부 테스트는 되지만 외부 입력창에서 마이크가 사라지거나 시작 직후 취소됐다.
갤럭시 SM-F966N, Android 17/API 37에서 다음 원인을 분리 재현했다.

1. 접근성 이벤트가 100ms보다 자주 오면 기존의 지연 예약을 매번 취소해 입력창 확인을 영원히 실행하지 못했다.
2. Telegram의 빈 입력창은 안내문을 실제 텍스트처럼 반환하고 커서는 `-1:-1`로 보고했다. 실제 키보드 연결에서는 내용이 비어 있고 커서가 `0:0`이었다.
3. 외부 앱 위에 앱의 녹음 Activity가 열리면 Telegram의 접근성 포커스 표시가 사라졌다. 기존 코드는 이를 사용자의 입력창 이동으로 판단했다.

## 적용

- 이벤트가 계속 와도 최초 예약은 실행하는 방식으로 합친다.
- 커서가 불명확한 Android 13+ 입력창은 같은 앱의 입력 연결에서 실제 내용·커서를 확인한다. 녹음 중과 입력 직전에 다시 비교한다. 입력 연결로 캡처한 내용은 연결이 사라졌을 때 `ACTION_SET_TEXT`로 덮어쓰지 않는다.
- 녹음 Activity가 실제 전면에 있고, 원래 편집 노드가 보이며, 같은 앱의 입력 연결이 유지되는 때만 포커스 표시 변화를 허용한다. 다른 편집 노드를 찾으면 취소하며 홈 이동·내용 변경·커서 이동 보호를 유지한다.
- 선택 변경 콜백의 이전 값 대신 캡처한 실제 커서와 새 위치를 비교한다.
- 시작 시 입력 연결과 `EditorInfo`를 보관하고 재시작/교체를 감지하면 취소한다. 결과는 보관한 연결로만 보낸다. 녹음 시작 검증 실패 시 세션도 정리한다. 독립 코드 검토에서 발견한 두 경로를 보완하고 재검토를 마쳤다.
- 제품 APK의 임시 진단 로그와 화면 메타데이터 dump를 제거했다. 새 의존성·권한·서버 인증 변경은 없다.

## 검증

- 결함별 실패 확인 → 수정 후 통과: 연속 이벤트, 잘못된 힌트/커서, 녹음창 전환.
- 별도 QA 앱의 7가지 검사 통과: `busy`, `placeholder`, `placeholder-content`, `paused`, `cursor`, `text`, `restart`. 최종 설치 직후 첫 QA 실행은 Android UiAutomation 연결 중 종료 오류로 실패했다. crash 로그에서 QA 프로세스 문제임을 확인했으며, 설치 후 연결을 기다려 같은 최종 APK에서 재실행해 통과했다.
- .6 수정판에서 Google 검색·ChatGPT·Grok·Telegram 저장한 메시지의 버튼/녹음 시작·유지/홈 취소 통과. 앱 전환 애니메이션 중 좌표를 누른 Google 시험 한 번은 실패했으며, 실제 검색창이 열린 것을 확인한 후 동일 APK에서 통과했다. 추가 입력 연결 보호가 들어간 최종 해시에서는 7개 회귀 검사와 Telegram을 재검증했다. 다른 세 앱의 최종 재검사는 사용자의 모바일망 테스트로 디버깅 연결이 끊겨 실행하지 못했다.
- 80개 Java 검사, 제품·QA APK 빌드와 Lint, APK v2 서명 검증 통과.
- Tailscale DNS가 꺼진 상태에서 일반 DNS/Google HTTPS와 개인 서버 인증·잘못된 인증 거부·TLS hostname 검증 등 11개 통신 검사 통과. 오디오나 AI 요청은 보내지 않았다.
- 모바일망 자동 검사에서는 Wi-Fi 변경으로 무선 디버깅이 끊겨 Wi-Fi 비활성 상태 확인에 실패했다. 성공으로 집계하지 않는다. Wi-Fi는 복원됐고 새 포트로 재연결했다. 후속 모바일 데이터 실사용 요청에 사용자가 `입력 잘되는거 같아`라고 답하고 녹음 중 키보드 숨김을 요청했다. 사용자 입력 성공 확인과 자동 네트워크 측정은 구분한다.

## 설치 상태

- 버전 `1.1.62-android.6`, versionCode `6`, 원래 서명으로 `adb install -r` 업데이트했다.
- APK: `output/android/Ultra-STT-1.1.62-android.6-debug.apk`
- SHA256: `6D5E3F275647BA4ADE5E51ED8579BD1231839AC5E9520040CA4D569BE5020C11`
- 마이크 권한 유지, 접근성 crashed services 없음, Samsung HoneyBoard 기본 키보드 유지.
- QA용 `.test`와 `.qa` 앱은 검증 후 제거했다. 본 앱·데이터·인증 정보는 제거하지 않았다.
- 기존 GitHub 릴리스·태그·배포 파일은 변경하지 않았다. 이번 수정은 커밋/푸시하지 않았다.
