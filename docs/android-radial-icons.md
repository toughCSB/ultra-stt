# Android 반원 모드 선택 자산

## 생성과 적용

2026-10-02 Codex 내장 `image_gen`으로 투명 PNG 여섯 장을 생성했다.
프롬프트에 `GPT-Image-2.5 Sunburst (gpt-image-2.5-sunburst)`를 요청했지만 도구에는 모델 선택 필드나 실제 모델 ID가 없었다.
따라서 요청 모델로 실제 생성됐다고 확인하지 않는다. 외부 API·다른 이미지 서비스는 사용하지 않았다.

각 프롬프트는 작은 Android 원형 버튼에 쓰는 단일 흰색 아이콘, 투명 배경, 큰 실루엣, 문자·테두리·검정 배경 없음,
세트 전체의 일관된 굵기·단순함을 요청했다. 모드별 그림은 다음과 같다.

| 파일 (`android/app/src/main/res/drawable-nodpi/`) | 요청한 그림 | 전체 버튼 색 |
| --- | --- | --- |
| `mode_original.png` | 높이가 다른 다섯 음성 파형 막대 | 녹색 `#20A044` |
| `mode_minimal.png` | 대각선 지우개 | 청록 `#008C78` |
| `mode_clean.png` | 마법봉과 반짝임 | 푸른 청록 `#007EA8` |
| `mode_structured.png` | 세 줄의 불릿 목록 | 파랑 `#2563EB` |
| `mode_professional.png` | 서류가방 | 남보라 `#5046C8` |
| `mic_glyph.png` | 전파 없는 직립 마이크와 받침 | 현재 모드의 색 |

원본 PNG를 변경 없이 사용한다. 픽셀 검사에서 모두 투명 영역이 있고 불투명 검정 픽셀은 없었다.
런타임에서 `inSampleSize=8`로 축소 디코딩하고 Android의 흰색 tint·FIT_CENTER로 표시한다.
원형 배경·현재 선택 테두리·드래그 확대·140ms 펼치기는 네이티브 UI이며, 생성 그림을 SVG나 HTML 캡처로 대체하지 않았다.

## 조작

48dp 모드 버튼 다섯 개가 마이크 왼쪽으로 180도 반원에 펼쳐진다.
누른 손가락을 옮기면 해당 모드의 이름과 굵은 흰 테두리가 나타나고, 손을 떼면 저장한다.
중앙 데드존이나 바깥에서 놓으면 기존 모드를 유지한다.
접근성 사용자는 전체 모드 이름으로 개별 아이콘을 클릭할 수도 있다.
대기 마이크에는 글자나 작은 모드 배지 없이 원 전체 색을 적용한다.

원문부터 전문적으로까지의 순서·그림·색은 `ModeArtwork`, 반원 좌표·선택 영역은 `RadialGeometry`가 관리한다.
이 업데이트는 STT·LLM 모델이나 데스크톱의 모드 프롬프트를 바꾸지 않는다.
