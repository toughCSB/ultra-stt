# Polish mode artwork

The Home and capsule mode controls use `src/assets/brand/polish-modes.png`, generated with the built-in `image_gen` tool. The user requested GPT Images 2; the tool exposes no model-selection field and its response did not identify the model, so that exact model is not verified.

The generated image remains the visual asset. CSS displays its five cells within real, accessible buttons; labels, checked states, focus, and persistence are implemented in the app. No image editing or replacement vector artwork was used.

## Generation prompt

Use GPT Images 2 as requested by the user if available. Create ONE production UI icon sprite-sheet image asset for Ultra STT, a premium desktop voice keyboard with near-black backgrounds and luminous mint/emerald green branding (#00e69a). Transparent background. Exact uniform 3-column by 2-row grid, six equal square cells, no gutters, all symbols perfectly centered within their cell and occupying about 60% of cell width. First row left to right: Original mode = speech waveform gently integrated with an unaltered page (original spoken words preserved); Minimal mode = a single graceful feather/pen stroke with two small text strokes (light touch); Clean mode = clean text strokes with one small sparkle. Second row left to right: Structured mode = orderly three numbered-list-like connected blocks (no actual numbers or text); Professional mode = elegant briefcase with a tiny document detail; sixth bottom-right cell entirely empty transparent. Cohesive polished soft 3D emerald translucent glass icons, crisp silhouettes at small size, restrained glow contained within each cell, no black opaque backgrounds, no borders, no labels, no typography, no watermark, no microphone or radio-wave logo repetition. All five icons identical visual weight and camera front view. This single sprite sheet will be displayed within real interactive buttons whose labels and selection states are rendered in HTML, so generate ONLY the imagery, not a UI screenshot. Prefer landscape canvas with exact 3:2 proportions.
