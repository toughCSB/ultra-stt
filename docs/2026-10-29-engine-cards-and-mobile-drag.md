# 엔진 선택 카드와 Fold7 버튼 이동 수정

## 설정 화면

- 데스크톱: 큰 카드 전체를 클릭해서 기존 연결(녹색)과 OpenAI 직접 연결(파란색)을 선택합니다. 처리 순서, API 과금, 키 저장 상태를 표시합니다.
- 선택한 초안과 실제 저장된 엔진 배지를 구분합니다. 기존 설정 저장 버튼을 눌러야 다음 녹음부터 적용됩니다. 엔진 카드 선택만으로 다른 미저장 설정을 함께 저장하지 않습니다.
- 모바일: 두 개의 큰 카드, 현재 선택 표시, 처리 경로, PC 필요 여부, 별도 API 과금을 표시합니다. 카드를 누르면 선택이 저장되며 다음 녹음에 적용됩니다.
- 기존 연결과 인증은 보존합니다. 실제 OpenAI 키나 유료 요청을 이번 검사에 사용하지 않았습니다.

## 이동이 막혔던 이유

1. 버튼의 수동 이동 범위도 입력칸보다 위로 제한했습니다. 구글 검색처럼 입력칸이 화면 상단에 있으면 세로 이동 범위가 거의 0이 됐습니다.
2. 실제 Fold7에서는 삼성 플로팅 키보드 창이 화면 대부분을 차지하는 것으로 보고됐습니다. `InputMethod`의 창 상단이 실제 키보드 상단이 아닌 상태에서 이동 범위를 다시 좁혔습니다. 키보드 창은 `Rect(0, 102 - 1080, 2520)`이지만 터치 영역은 아래쪽에 따로 있었습니다.
3. 빠른 제스처의 마지막 `ACTION_UP` 좌표를 이동에 반영하지 않아, 마지막 이동 이벤트가 적거나 생략되면 탭으로 오인하거나 중간 위치에 멈출 수 있었습니다.

기본 자동 위치와 수동 이동 범위를 분리했습니다. 기본은 입력칸을 피하고, 직접 끌 때는 **화면 안전 영역 전체**를 사용합니다. 사용자가 원하면 키보드 위에도 놓을 수 있습니다. 화면 밖으로는 나가지 않으며 가장자리 여백은 16dp로 두었습니다. 접기·펼치기는 기존 상대 위치 저장을 유지합니다.

드래그 중 일시적인 입력 포커스 갱신이 버튼을 제거하지 않도록 했고, 잠금·화면 꺼짐·녹음 대상 보호는 유지했습니다. 짧은 탭은 녹음, 즉시 움직이면 이동, 움직이지 않고 길게 누르면 진동과 모드 선택이라는 구분은 그대로입니다.

## 검증

- 수정 전 테스트 두 개가 실패하는 것을 확인했습니다: 상단 검색칸의 이동 제한, 전체 높이 IME 창의 이동 제한.
- 수정 후 Android local checks **120개**, 앱·테스트 APK 빌드, lint, 서명 확인 통과.
- 프런트엔드 **436개** 테스트, 타입·lint·format·production frontend build 통과.
- Fold7의 실제 Google 검색창에서 버튼이 `Rect(897,138–1041,282)`에서 `Rect(252,453–396,597)`로 이동했습니다. 가로·아래 이동, 갱신 후 위치 유지, 취소 시 복원, 길게 눌러 반원 메뉴 열기까지 통과했습니다. 녹음·전송·검색 실행은 하지 않았습니다.
- 기기에서 실제 `BubbleView` 터치 이벤트 검사 **5개**와 OpenAI 경로의 **오프라인 mock 21개**가 통과했습니다. mock은 실제 API의 속도·품질·인증 검증이 아닙니다.
- 기기 내부 instrumentation은 대상 앱 프로세스를 중단해 접근성 서비스를 방해할 수 있어, 실제 드래그는 별도 QA 패키지의 `EditorChecks current-drag`로 검증했습니다. 검사 후 기존 앱을 재설치해 서비스를 복원했고 이번에 만든 임시 QA 앱은 제거했습니다. 접근성 권한을 자동으로 변경하지 않았습니다.
- 테스트 중 위치 변경은 원래 저장 좌표 `x=0.99666667, y=0.0`으로 복원했습니다. 실제 화면 테스트에서 개인 검색 내용은 입력·수정하지 않았고 캡처를 README나 원격 저장소에 넣지 않았습니다.

설치한 Fold7 버전은 **1.1.64-android.12 / versionCode 12**입니다. APK SHA256:

`9211CCA83A7DD2C0916835272678B2CCD6CA347CC4843A95390F51D36A220BBB`

증거는 저장소 상위 `qa/engine-profiles-20261029/`의 `samsung-ime-red.log`, `samsung-ime-green.log`, `fold-google-ime-fixed.log`, `fold-direct-mock-final.log`, `fold-view-gestures-final.log`, `engine-cards-*.log`에 있습니다. 이전 .10 APK도 해당 폴더에 보관했습니다. 되돌리기에는 이 APK를 사용하되 앱 데이터 삭제 없이 버전 다운그레이드 허용 여부를 먼저 확인해야 합니다.

데스크톱 화면은 코드·컴포넌트 검사·빌드까지 확인했습니다. 이 세션의 Computer Use native pipe 및 연결 브라우저가 없어 실제 Windows 화면의 시각 검사는 하지 못했습니다. SB/Home/Mac 설치본 교체, GitHub push/release는 이번 작업에 포함하지 않았습니다. 전사 엔진 자체의 실제 API 성능 비교는 별도 후속 검증입니다.
