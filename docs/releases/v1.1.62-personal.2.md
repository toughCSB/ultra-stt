# Ultra STT Personal Preview 2 — Android .9

익숙한 키보드를 바꾸지 않고, 작은 음성 버튼으로 받아쓰는 개인용 프리뷰입니다. 이번 업데이트의 중심은 **Android `1.1.62-android.9`**입니다. Windows·Mac 파일은 첫 프리뷰의 `1.1.62`와 바이트 단위로 동일하며, 데스크톱을 다시 설치할 필요는 없습니다. 저장소와 릴리스는 기존처럼 비공개입니다.

## 모바일에서 달라진 점

- **기존 키보드는 그대로:** 입력창을 누르면 작은 음성 버튼이 나타납니다. 버튼을 한 번 눌러 녹음을 시작하고, 중앙창의 종료 버튼으로 마칩니다.
- **가리지 않는 녹음창:** 녹음 시작 시 키보드를 숨기고, 화면 중앙에 264dp 크기의 반투명 녹색 패널을 표시합니다. 기존 Ultra STT 원본 타이포그래피를 사용했습니다.
- **상태를 분명하게:** 현재 모드·녹음 시간·맥박 애니메이션을 보여 주고, 종료 후에는 `변환 중` → `전송 완료`를 표시한 뒤 약 1.2초 후 닫힙니다. 여기서 전송 완료는 **입력칸에 문장을 넣었다는 뜻**이며, 채팅의 보내기 버튼을 누르지는 않습니다.
- **다섯 모드를 빠르게:** 원문·최소·깔끔하게·구조화·전문적으로를 서로 다른 녹색·파란색 톤으로 구분합니다. 대기 버튼을 길게 눌러 반원형 메뉴에서 선택하거나 녹음창 안에서 바꿀 수 있습니다.
- **실제 앱 진입 문제 수정:** ChatGPT·Grok 홈 화면 위젯 진입과 늦게 나타나는 입력창에서 버튼을 놓치던 경로를 보완했습니다. 포커스 조회가 잘못된 호스트를 반환하면 활성 앱 창에서 실제 포커스된 편집 노드만 제한적으로 찾습니다.
- **잘못된 곳에 쓰지 않도록:** 비밀번호·포커스 없는 입력칸을 제외하고, 녹음 중 입력 대상이나 내용이 바뀌면 취소합니다. X 또는 Home으로도 취소할 수 있습니다.

## 다운로드와 업데이트

| 파일 | 용도 |
| --- | --- |
| `Ultra-STT-1.1.62-android.9-debug.apk` | 업데이트된 Android 앱. 기존 앱을 삭제하지 않고 설치해 설정을 유지합니다. |
| `Ultra-STT-1.1.62-windows-x64-setup.exe` | 첫 프리뷰와 동일한 Windows x64 설치 파일. |
| `Ultra-STT-1.1.62-macos-arm64.zip` | 첫 프리뷰와 동일한 Apple Silicon Mac 앱. |
| `android-recording-panel-9.png` | 실제 모바일 녹음창 스크린샷 원본. |
| `SHA256SUMS.txt` | 위 네 파일의 SHA-256 확인값. |

새 기기에는 본인의 서버 연결 설정과 마이크·접근성 허용이 필요합니다. APK나 저장소에 서버 토큰·Codex 로그인 정보는 포함하지 않았습니다. 서버는 켜져 있어야 합니다. 앱 전용 주소 조회를 사용하므로 휴대폰 전체의 Tailscale DNS 설정을 바꿀 필요가 없으며, Tailscale 연결이 가능한 모바일 데이터에서도 사용할 수 있습니다. 개발용 무선 디버깅의 Wi-Fi 조건과 평소 음성 입력의 연결 조건은 다릅니다.

Windows는 미서명, Mac은 ad-hoc 서명이며 notarization된 배포본이 아닙니다. Android는 기존 개인용 debug 서명 APK입니다. 운영체제의 보안 경고를 무조건 해제하지 마세요. 체크섬은 파일 일치 확인용이며 배포자 인증을 대신하지 않습니다. 자동 업데이트용 `latest.json`이나 서명 업데이트 패키지는 게시하지 않습니다.

## 확인한 범위와 남은 한계

- 오프라인 빌드, Java 로직 검사 **80개**, 제품·QA lint 오류 0, 기존 Android 서명 검증을 통과했습니다. 경고가 전혀 없다는 의미는 아닙니다.
- 최종 .9 실기기 검사 **18개**와 실제 ChatGPT·Grok 홈 위젯 진입 **각 5회**를 통과했습니다. 입력칸을 다시 누르지 않고 버튼 출현, 녹음 시작, 키보드 숨김, 패널, 취소·정책 복원을 확인했습니다.
- 이번 자동 검사는 음성을 전사 서버에 업로드하지 않았습니다. 이전 .5의 사용자 실발화→문장 입력 성공과 통신 검사 10개를 최신 .9의 새 전체 경로 검증으로 표현하지 않습니다. 모든 앱·기기에서 동작한다고 보장하지 않습니다.
- **Home PC 절전 복귀 후 단축키 무반응은 관찰 중입니다.** 재시작으로 복구됐지만 당시 원인은 확정하지 못했습니다. 사용자 요청대로 이번에 복구 기능이나 별도 프로그램을 추가하지 않았습니다.
- 기존 GitHub CI의 포맷·오타·의존성 감사 및 CodeQL 실패 기록은 남아 있습니다. 이번 Android 로컬 검증이 저장소 전체 CI·보안 검사 통과를 의미하지 않습니다.
