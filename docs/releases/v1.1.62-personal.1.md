# Ultra STT 1.1.62 — Desktop + Android Personal Preview

Windows·Mac·Android를 묶은 첫 **개인용 프리뷰**입니다. 공개 배포·스토어 심사·자동 업데이트용 릴리스가 아닙니다. 저장소는 사용자 소유 `toughCSB/ultra-stt`의 **private** 상태를 유지하며, 접근 권한이 있는 계정만 다운로드할 수 있습니다.

## 다운로드

| 기기 | 파일 | 상태 |
| --- | --- | --- |
| Windows x64 | `Ultra-STT-1.1.62-windows-x64-setup.exe` | NSIS 설치 프로그램, 미서명 |
| Apple Silicon Mac | `Ultra-STT-1.1.62-macos-arm64.zip` | 1.1.62 설치 앱을 패키징, ad-hoc 서명, notarization 없음 |
| Android (min SDK 28) | `Ultra-STT-1.1.62-android.5-debug.apk` | 개인 debug APK, 기존 앱 업데이트용 서명 유지; 실기기는 갤럭시 SM-F966N 검증 |
| 무결성 확인 | `SHA256SUMS.txt` | 위 세 파일의 SHA-256 |

체크섬은 다운로드가 원본 파일과 같은지 확인하는 값이며, 신뢰된 배포자 서명을 대신하지 않습니다. 운영체제의 보안 경고를 확인하고 본인이 요청한 파일인지 판단해 설치하세요. 전체 보안 기능을 끄지 마세요.

## 달라진 기능

- **다섯 다듬기 모드:** 원문·최소·깔끔하게·구조화·전문적으로. 원문도 오인식과 오타 등을 정리하는 AI 모드이며, AI 끄기와는 다릅니다.
- **데스크톱 빠른 전환:** 홈의 그림 버튼·트레이 우클릭·녹음 캡슐에서 선택하고 현재 선택을 표시·저장합니다. 캡슐의 Esc 취소와 창 테두리·아이콘도 개선했습니다.
- **쓸 수 있는 기록:** 홈의 날짜별 그래프를 눌러 기록을 필터링하고, 기록에서 원문/결과 검색·비교·복사·교정을 할 수 있습니다. 그래프는 현재 불러온 최대 200건 기준입니다.
- **Android는 키보드가 아닙니다:** 삼성 키보드·Gboard를 유지하고 활성 입력창에 작은 음성 버튼을 띄웁니다. 한 번 터치해 시작, 다시 터치해 종료합니다.
- **보기 쉬운 모바일 조작:** 모드별 버튼 전체 색상, 길게 누르기→반원 아이콘으로 드래그→놓아서 선택. 녹음 중 흰 종료 버튼·시간·맥박 애니메이션, 처리 중 회전 표시를 제공합니다.
- **취소 반복 수정:** 처리 중 재터치가 녹음을 취소하지 않습니다. 녹음과 네트워크 작업을 분리하고, 입력창이 바뀌면 오래된 결과가 다른 곳에 들어가지 않도록 버립니다.
- **안전한 개인 서버 연결:** 휴대폰의 주소 조회 실패는 앱 전용 IP 매핑으로 해결했습니다. 기존 HTTPS 주소·인증서 검사·서버 인증을 유지하고 VPN 전체 설정을 바꾸지 않습니다.
- **앱 전용 Codex:** 서버의 개발 지침·스킬과 분리한 설정과 로그인으로 실행합니다. Fast 요청과 작업별 추론을 사용하되, 현재도 AI 처리에는 수 초가 걸릴 수 있습니다.

## 왜 PC가 필요하나요?

휴대폰·Mac·집 PC는 **녹음기**, SB PC는 **함께 쓰는 처리 작업실**입니다. 녹음을 개인 서버에 보내면 PC의 Whisper가 전사하고, 켜 둔 경우 AI가 다듬어 원래 기기에 돌려줍니다. 휴대폰에 무거운 모델을 설치하지 않는 대신 **SB PC·앱/서버·Tailscale이 켜져 있어야 합니다**. AI 다듬기가 켜져 있으면 전사 텍스트는 OpenAI로 전송됩니다. 완전한 오프라인 모바일 앱이 아닙니다.

설치 파일에는 서버 토큰·Codex 인증·Whisper 모델이 없습니다. 기기별 연결 설정이 필요합니다. 승인된 갤럭시와 집 PC에는 따로 설정했으며, Android는 Keystore로 암호화하고 Windows는 OS 자격 증명 저장소를 사용합니다. 집 PC는 `Ctrl+Alt+R` 토글, Minimal, 커서 입력으로 준비했습니다. 원격 받아쓰기에는 집 PC의 별도 Codex 로그인이 필요 없습니다. 클라이언트의 로컬 AI 로그인 검사나 고급 Ask·번역 설정을 원격 서버의 기능/인증 확인으로 해석하지 마세요.

## 설치·업데이트

1. **Windows:** x64 설치 프로그램으로 설치합니다. 새 기기는 음성 제공자 또는 본인 서버를 설정해야 합니다. 집 PC는 이미 설정했습니다.
2. **Mac:** ZIP을 풀어 앱을 Applications에 넣고 마이크·손쉬운 사용 권한을 직접 허용합니다. Apple Silicon용이며 notarization된 앱이 아닙니다.
3. **Android:** APK로 기존 Ultra STT를 업데이트합니다. **앱 삭제·데이터 지우기는 필요 없습니다.** 마이크와 ‘Ultra STT 작은 음성 버튼’ 접근성을 허용하고 기존 키보드를 그대로 사용합니다. 최초 연결은 [Android 안내](https://github.com/toughCSB/ultra-stt/blob/v1.1.62-personal.1/android/README.md)를 따릅니다.
4. 자동 업데이트용 `latest.json`은 제공하지 않습니다. 이후에도 다운로드 파일로 수동 업데이트합니다.

## 확인한 것과 남은 것

- 데스크톱의 기존 frontend 414개·Windows native 629개·Mac native 635개 검증 기록이 있습니다. 외부 서비스용 ignored 테스트를 전부 실행했다는 뜻은 아닙니다.
- 이번 패키징에서 Windows production 빌드와 집 PC 설치·실행·NSIS payload 일치·평문 없는 인증 저장·인증된 HTTPS 연결을 확인했습니다. Mac은 설치된 arm64 1.1.62 앱을 별도 복사해 개인 PC의 절대 경로 resource를 일반 runtime marker로 바꾸고 ad-hoc 재서명·검사한 번들을 패키징했습니다. 기존 Mac 설치 앱은 변경하지 않았습니다.
- Android Java **80개 검사**, APK 빌드·v2 서명 검사가 다시 통과했고 Lint 오류는 0입니다. SDK XML·Gradle 경고는 남습니다. 앞선 기기 통신 **10개 검사**와 사용자의 실제 한국어 음성→앱 테스트 입력창 삽입 확인이 있습니다.
- 사용자가 집 PC에서도 실제 음성→커서 입력 성공을 확인했습니다. 모든 외부 앱·특수 편집기 호환성을 보장하지 않으며, 최신 Mac의 평소 입력창·물리적 Esc는 별도 수동 확인 항목입니다.
- Linux·Intel Mac·Windows ARM·native iOS는 이번 배포 대상이 아닙니다. 모바일 기록 관리·휴대폰 자체 오프라인 AI·Play Store 배포도 포함하지 않습니다.
