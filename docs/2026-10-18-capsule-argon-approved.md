# 확정된 AGY Argon 실행창 — v1.1.69

## 디자인 결정

사용자가 다섯 시안 중 **1번 원본 터미널 정밀형(Original Terminal Precision)**을 확정했습니다. AGY가 작성한 최종 `DESIGN-NOTES.md` 0절을 기준으로 기존 React 실행창에 표현만 이식했습니다. 시안 갤러리의 합성 녹음·타이핑 코드는 제품에 포함하지 않았습니다.

- 일반 STT: 원래 에메랄드 `#00e676`, `#0f1b13` → `#09110c` 표면.
- 바로입력: 사파이어 `#38bdf8`, `#0c2242` → `#061224` 표면, 파란 파형·배지·STT 버튼.
- 오류: `#ff4d4d`, `#270d12` → `#1b090c` 표면, 두 줄 오류 상세.
- 원형 원본 로고, 상태/타이머와 파형, 오른쪽 스타일·LIVE/STT·취소 버튼의 세 영역을 사용합니다. 주요 버튼 높이는 44px입니다.

## 실제 앱에 맞춘 보완

긴 `원문 · Original` 버튼이 중앙 영역을 좁히더라도 배지가 잘리거나 두 줄이 되지 않도록 보조 표기를 `STT · AI`로 압축했습니다. 툴팁에는 `STT · AI 다듬기` 전문을 유지합니다. AI를 끄면 `STT`만 표시합니다.

갤러리의 큰 바깥 그림자를 그대로 복사하면 기존 네이티브 창의 12px 투명 여백에서 그림자가 사각형으로 잘립니다. 창 크기를 늘리는 대신 그림자를 `0 3px 6px`로 제한하고 원래의 얇은 곡선 테두리와 상단 에메랄드 엣지를 유지했습니다.

스타일 버튼은 고정 좌표 오버레이 대신 실제 액션 행의 레이아웃에 참여합니다. 클릭·포인터 전파 차단과 기존 메뉴 저장·Esc 취소 로직은 유지합니다. 메뉴를 펼쳐도 기존 `560 × 112` 실행창과 네이티브 `584 × 136` 프레임은 확장하지 않습니다.

## 보존 범위

STT/LLM 모델·추론·프롬프트, 녹음 및 분할 처리, 실패 음성 보존, 입력 대상 보호, 단축키, 모니터 선택·드래그, 타이머, 자동 실행 및 인증 방식은 변경하지 않았습니다. 기존 미커밋 작업과 사용자 기록을 보존합니다. 버전 식별은 다섯 버전 파일에서 `1.1.69`로 맞췄습니다.

## 검증과 한계

- 관련 회귀 검사 78개, 전체 프런트엔드 검사 477개와 타입·린트·서식·웹 빌드가 통과했습니다.
- 실제 Chrome에서 제품 React 컴포넌트를 합성 IPC에 연결해 원형 로고, 녹색 STT, 파란 LIVE, 메뉴 선택을 확인했습니다. 긴 Original 라벨 선택 후 상태 영역의 실제 폭과 내용 폭이 같아 잘림이 없었습니다.
- 메뉴 전후 외곽은 동일했고 합성 네이티브 위치·크기 변경 호출도 증가하지 않았습니다. 실제 녹음 기한 이벤트 형식의 고정 시작 시각을 사용해 메뉴 전환 중 타이머가 이어지는 것을 확인했습니다.
- 위 브라우저 확인은 실제 마이크 입력이나 다른 앱 커서 입력을 재현한 것은 아닙니다. 플랫폼 빌드·서명·설치·설치 후 검사는 별도 영수증과 인수 문서에 기록합니다. 빌드 통과를 설치 완료로 간주하지 않습니다.

## 설치 결과

사용자의 ‘SB·Home·Mac 모두 업데이트’ 승인 후 세 곳의 기존 앱을 `1.1.69`로 교체했습니다. SB·Home은 동일한 Windows 실행 파일이며 내장 프런트엔드의 실제 백엔드 호출과 초기/중복 자동 실행 시 창이 숨겨지는 것을 확인했습니다. Home은 사용자 Session 1에서 설치했고 이번 임시 설치 작업은 제거했습니다.

Mac은 처음에는 화면 잠금 때문에 대기 상태를 확정하지 못해 **원본 앱을 종료하기 전에 중단**했습니다. 사용자 잠금 해제 후 원래 대기 검사를 통과해 설치했으며 서명·버전·실행 파일 해시·프런트엔드 초기화·기존 설정/인증 및 83개 기록 보존을 확인했습니다. 기존 `selected_text_enabled=false`는 그대로입니다.

Windows 전체 검증은 프런트엔드 477개·Rust 713개·통합 9개가 통과했고 npm audit은 취약점 0개였습니다. 최종 release 실행 파일의 UIA helper 통합 검사도 3개 통과했습니다. Mac은 프런트엔드 477개·Rust 706개·통합 1개와 production 빌드/엄격한 코드 서명이 통과했습니다. 기존 ignored 검사 3개는 그대로입니다.

두 플랫폼의 빌드 입력 47개 파일이 해시까지 일치합니다. 이번 변경을 제외한 기존 작업 보존도 별도로 확인했습니다. 실제 사람의 마이크 발화와 외부 앱 커서 입력, macOS 선택 텍스트 실사용을 새 버전에서 완료했다고 주장하지 않습니다. Git commit/push/release는 수행하지 않았습니다.
