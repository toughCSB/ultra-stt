# Android 중앙 녹음창 — .8

## 요청과 선택

사용자는 작은 버튼 위치 이동보다 PC 실행창 같은 별도 녹음 화면을 요청했다.
대기 버튼은 기존 위치·다섯 색상·길게 눌러 반원 모드 선택을 유지한다.
녹음 시작 시 키보드를 먼저 접고 화면 중앙에 반투명 녹색 패널을 표시한다.
드래그 위치 이동은 이번 변경에 포함하지 않았다.

## 동작

1. `듣고 있어요`: 맥박 애니메이션, `분:초`, 현재 모드, 녹음 종료 버튼.
2. 모드 이름을 누르면 패널 안에서 다섯 전체 이름을 선택한다. 새 포커스 창을 열지 않는다.
3. 종료 시 `변환 중…`과 회전 표시. 중복 종료·모드 변경을 막지만 `✕`로 취소할 수 있다.
4. 원래 입력창으로 전달한 뒤 `전송 완료`를 1.2초 보여 주고 닫는다. 원래 키보드 정책을 복원한다.
5. 실패·대상 변경·홈 이동은 완료로 위장하지 않고 기존 취소 경로를 사용한다.

완료 표시는 `commitText` 전달 요청 또는 기존 `ACTION_SET_TEXT` 성공을 뜻한다.
원격 앱 내부의 실제 삽입 완료를 독립적으로 읽어 확인하는 새 프로토콜은 추가하지 않았다.
ChatGPT·Telegram의 메시지 보내기 버튼을 누르지 않는다.

## 구현

- `RecordingPanelView`: Android 기본 View로 반투명 녹색 배경·마이크·텍스트·애니메이션을 구성한다. 새 이미지 생성이나 라이브러리는 없다.
- `RecordingActivity`: 기존 비포커스 창을 중앙에 배치하고 작은 화면에서는 스크롤 가능하게 한다. 완료 지연 콜백은 취소·파괴 시 제거한다.
- `VoiceAccessibilityService`: 결과 전달 직후 캡처·요청·대상 보호 상태를 해제하되 완료창이 닫힐 때까지 작은 버튼 재등장과 키보드 정책 복원을 유예한다.
- 기존 입력창 확인, 앱 전환 취소, .7의 키보드 숨김/복원, 서버 인증·통신 형식은 유지한다.
- QA는 제품을 계측해 접근성 서비스를 종료하지 않도록 별도 패키지로 실행한다. 제품 View 세 파일만 Gradle 생성 디렉터리에 복사하므로 QA에 마이크 권한을 추가하지 않는다.

## 확인한 결과

- 설치 버전 `1.1.62-android.8` / versionCode 8, 갤럭시 SM-F966N Android 17.
- APK SHA256 `F80C8BF2034DE89DD503DAC56C8AA5F0666820D8B618320D48F27475B7CD7F97`; 설치된 base.apk와 일치.
- `scripts/build-android.ps1 -Offline -IncludeDeviceTests`: 80개 Java 검사, 제품/QA lint, APK·계측 앱 빌드, 기존 키의 v2 서명 검사 통과.
- 실기기 15개: `panel-states`, `panel-cancel`, `keyboard`, `keyboard-blur`, `keyboard-cancel`, `keyboard-blur-content`, `keyboard-edit`, `busy`, `placeholder`, `placeholder-content`, `paused`, `cursor`, `text`, `restart`, `late-visible`.
- `panel-states`는 실제 제품 View의 시간·모드 callback·종료·변환 중 잠금·취소·완료·늦은 갱신 거부를 검사한다. 서버 전체 경로 검사는 아니다.
- 실제 ChatGPT에서 작은 버튼 → 키보드 숨김 → 중앙 녹음창 → 마이크 유지 → Home 취소·표시 모드 복원 통과. 설치판의 중앙창 디자인은 실제 스크린샷으로 확인했다.
- 비포커스 창은 이 갤럭시의 UiAutomation에서 빈 접근성 루트로 노출됐다. UI 텍스트 탐색 실패를 제품 실패로 오인하지 않고, 실제 WindowManager 좌표로 중앙 배치와 취소 터치를 검사했다. 제품을 포커스 가능한 창으로 바꾸지 않았다.
- 종료 후 마이크 비활성, 키보드 정책 0, 기본 Samsung HoneyBoard 유지 확인. 자동 검사에서는 음성을 서버로 보내지 않았다.

## 남은 확인과 보존

사용자에게 실제 발화 후 `변환 중 → 전송 완료 → 자동 닫힘`과 커서 입력을 요청했다. 아직 답변 전이며 전체 실사용 완료로 기록하지 않는다.
DNS/VPN·인증·기본 키보드·기존 앱 데이터는 변경하지 않았다. commit/push/release는 하지 않았다.
