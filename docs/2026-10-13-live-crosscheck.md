# 바로입력 교차 검증과 Home 설치 — 2026-10-13

## 기준과 변경

기준은 원격·로컬 `main`의 `abe9e84`다. 기존 미추적 조사 문서 3개와 설정·인증·기록은 보존했다. 이번 작업은 Home 설치와 바로입력 교차 검증이며, GitHub 워크플로 복구·푸시·릴리스는 수행하지 않는다.

바로입력의 마지막 인식 요청이 일시적으로 실패하면, `recognise()`가 재시도 가능한 실패를 `Ok(None)`으로 반환하고 종료 경로가 이를 ‘음성 없음’으로 처리해 현재 음성을 소비하는 오류를 발견했다. 실제 HTTP 503 후 정상 응답을 돌려주는 회귀 검사에서 최종 문장이 빈 문자열로 사라지는 것을 먼저 재현했다. 종료 경로는 이제 음성을 소비하지 않고 기존 450ms 간격으로 재시도한다. 기존 3회 실패 한도는 유지하며 반복 실패 시 오류 이벤트와 소비되지 않은 음성을 확인했다. 모델·AI 다듬기·입력 대상 보호는 변경하지 않았다.
