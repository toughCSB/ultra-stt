**녹음창 구성:** 위에는 원본 로고와 `× 취소`, 가운데에는 움직이는 마이크·상태·녹음 시간, 아래에는 현재 모드와 큰 `녹음 종료` 버튼이 있습니다. 녹음 시작과 함께 키보드가 접히고, 모드 이름을 누르면 다섯 선택지가 펼쳐집니다.

| --- | --- |
| 시작 | 입력칸의 작은 마이크를 누르면 키보드가 접히고 녹색 중앙창이 뜹니다. |
| 녹음 | 현재 모드·시간·움직이는 마이크가 보입니다. 모드 이름을 눌러 바꿀 수 있습니다. |
| 종료 | 녹음 종료를 누르면 `변환 중…`을 표시하고 중복 터치를 막습니다. |

중앙창은 너비 264dp, 더 투명한 배경, 원본 Ultra STT 타이포그래피로 정리했습니다.
ChatGPT·Grok 위젯 진입, 늦게 보이는 입력칸 감지, 키보드 숨김 전후의 연결 처리를 보완했습니다.
앱 전용 연결은 Tailscale DNS를 켜지 않아도 됩니다.

입력칸을 다시 누르지 않고 버튼이 뜨는지 확인했습니다. 자동 검사는 실제 발화를 전송하지 않았으며 모든 앱 호환성을 보장하지 않습니다.

## 무엇을 하는 앱인가요?

입력창에서 커서를 옮기지 않고 말하세요. 음성을 인식한 뒤 원하는 만큼만 다듬어, 사용 중인 앱에 입력합니다.

- **현재 커서에 입력:** 전역 단축키, 누른 채 말하기·토글 녹음, 키보드 입력·클립보드 출력.
- **내 말에 맞는 다듬기:** 원문 · 최소 · 깔끔하게 · 구조화 · 전문적으로.
- **어디서든 모드 전환:** 트레이 우클릭, 홈 이미지 버튼, 음성 실행창 선택 메뉴.
- **쓸모 있는 기록:** 날짜별 사용량 확인, 날짜 클릭 필터, 원시 전사·최종 문장 검색과 복사.
- **품질을 지키는 최적화:** GPU 모델 예열, 연결 재사용, Codex Fast, 작업별 Medium/High 자동 선택.
- **개발 환경과 분리:** 앱 전용 Codex 지침·로그인으로 개발용 설정을 끌어오지 않습니다.
- **Mac에서도 같은 받아쓰기 모드:** Windows 서버의 GPU·AI를 활용하고 Mac 커서에 입력합니다.

## 왜 이렇게 만들었나요? 쉽게 이해하기

**휴대폰·Mac·집 PC는 ‘녹음기’, SB PC는 ‘음성을 글로 바꾸는 처리실’입니다.**
휴대폰에서 “내일 오후 세 시에 회의가 있습니다”라고 말하면 다음 순서로 움직입니다.

```text
휴대폰·Mac·집 PC에서 녹음
  → 개인 연결망으로 SB PC에 전달
  → Whisper가 음성을 글자로 변환
  → 선택한 모드로 AI가 문장을 다듬음 (끄면 생략)
  → 녹음을 시작했던 입력창의 커서에 입력
```

이 설명은 지금 사용 중인 **개인 서버 구성**입니다. 앱 전체가 항상 인터넷 없이 작동한다는 뜻은 아닙니다.
음성 인식은 SB PC에서 실행하지만, AI 다듬기를 켜면 전사문은 OpenAI로 전달됩니다.
클라이언트와 SB PC 사이 연결이 필요하고, **SB PC·Ultra STT 서버·Tailscale이 켜져 있어야** 합니다.
집 PC에 큰 음성 모델이나 개발용 Codex 환경을 또 설치하지 않아도 서버 쪽의 처리 기능을 쓸 수 있습니다.

### 1. 왜 휴대폰 키보드를 만들었다가 없앴나요?

처음에는 음성 기능이 있는 키보드를 만들었습니다. 하지만 그러면 평소 쓰던 삼성 키보드나 Gboard를
바꿔야 해서 일반 타이핑까지 불편해집니다. 그래서 **기존 키보드는 그대로 두고, 입력창 옆에 작은 마이크만** 붙였습니다.

Android의 **접근성 권한**은 여기서 ‘현재 입력할 칸을 찾고 그 커서에 글을 넣는 허가’입니다.
비밀번호 칸에서는 작동하지 않고, 화면 이력을 모으지 않습니다. 기존 입력 내용은 덮어쓰기 방지용으로
기기 안에서 잠깐 비교할 뿐 서버에 보내지 않습니다. 접근성 편집을 지원하지 않는 특수 입력창은 제한이 있습니다.

### 2. 작은 마이크는 어떻게 쓰나요?

| 하고 싶은 일 | 조작과 표시 |
| --- | --- |
| 녹음 시작 | 작은 마이크 터치 → 키보드 접힘 → 중앙 녹색 창에 모드·시간·마이크 애니메이션 |
| 녹음 종료와 입력 | 중앙창의 녹음 종료 → 변환 중 → 커서에 전달 → 전송 완료 후 창 닫힘 |
| 말투·정리 방식 변경 | 길게 누른 채 왼쪽 반원의 아이콘으로 드래그하고 손을 떼기 |
| 입력 위치가 바뀜 | 다른 앱·커서·입력 내용으로 바뀌면 취소하여 엉뚱한 곳에 입력하지 않음 |

원문·최소·깔끔하게·구조화·전문적으로는 버튼 전체의 녹색→청록→파랑 계열 색과 서로 다른 그림으로 구분합니다.
녹음 중에는 중앙창의 모드 이름을 눌러 바꿀 수 있고 그 녹음에 적용합니다. 처리가 시작되면 모드 선택과 종료 버튼을 잠급니다.

이전에는 녹음 종료 뒤 흐릿한 마이크만 보여 ‘안 눌렸나?’ 하고 다시 누르면 처리까지 취소됐습니다.
지금은 **녹음·변환·완료를 따로 표시하고, 처리 중 재터치는 취소하지 않습니다.** 취소하려면 중앙창 오른쪽 위 `✕`를 누릅니다. `전송 완료`는 입력창에 텍스트를 전달했다는 뜻이며 대화 메시지를 자동으로 보내지 않습니다.
또 녹음과 서버 통신을 별도의 작업 줄로 나누어, 통신 대기가 다음 녹음 실행을 막지 않도록 했습니다.

### 3. 왜 연결에 Tailscale·HTTPS·인증이 모두 필요한가요?

세 가지는 같은 일을 중복하는 것이 아니라 각각 다른 문을 지킵니다.

- **Tailscale:** 내 기기끼리 오가는 개인 통로입니다. 이 기능에 공개 인터넷 서버를 열 필요가 없습니다.
- **HTTPS:** 통신 내용을 암호화하고 ‘정말 그 서버인가’를 인증서로 확인합니다.
- **인증 토큰:** 서버가 허용한 클라이언트인지 확인하는 출입증입니다. 모델 사용을 아무 요청에나 허용하지 않습니다.

휴대폰에서는 서버의 **이름 주소를 IP 주소로 찾는 과정(DNS)**이 실패했습니다. 전화번호부에서 이름을 찾지 못한 상황과 같습니다.
그래서 Android 앱에만 승인된 SB PC의 번호(IP)를 알려 줬습니다. URL의 서버 이름은 그대로 두므로
HTTPS의 인증서 확인도 그대로 합니다. **인증을 끄거나 다른 앱의 VPN·DNS 설정을 바꾸는 방식은 아닙니다.**
PC의 Tailscale IP가 바뀌면 앱 연결 정보를 다시 받아야 합니다.

토큰은 APK·설치 파일·GitHub에 넣지 않습니다. Android에서는 한 번 받은 연결 정보를
기기의 안전한 키 저장소로 암호화하고, 전달에 사용한 임시 파일은 지웁니다.
그러므로 **APK를 내려받는 것과 서버 접속 허가를 받는 것은 별개**입니다. 다른 기기는 각자 연결 설정이 필요합니다.

### 4. 왜 녹음 창과 커서 보호가 복잡한가요?

Android는 마이크를 쓰는 앱이 사용자에게 보이도록 제한합니다. 그래서 녹음할 때만 작은 창을 띄우되,
평소 입력창과 키보드의 포커스는 유지합니다. 보이지 않는 곳에서 마이크를 계속 켜 두는 방식이 아닙니다.

서버가 처리하는 동안 사용자가 다른 대화방으로 옮겼다면, 결과를 새 대화방에 넣으면 안 됩니다.
그래서 시작할 때의 입력창·내용·커서를 기억하고, 바뀌면 취소하며 늦게 도착한 결과도 버립니다.
빈 입력창의 안내 문구를 실제 글자로 잘못 읽던 문제도 고쳤습니다. 커서를 확인할 수 없는 **내용 있는 칸**은 임의로 덮어쓰지 않습니다.

### 5. Codex를 분리했다는 말은 무슨 뜻인가요?

개발용 Codex와 앱의 AI 다듬기는 ‘같은 프로그램, 다른 작업방’입니다.
SB 서버의 Ultra STT는 **앱 전용 `CODEX_HOME`**과 짧은 받아쓰기 지침을 사용합니다.
개발용 지침·스킬·MCP·플러그인·로그인 파일을 통째로 가져오지 않으며, 앱 전용 로그인은 공식 로그인으로 따로 준비했습니다.
집 PC나 휴대폰이 개발용 Codex 세팅을 끌어안고 다듬기를 실행하는 구조가 아닙니다.

원격 받아쓰기는 서버에서 한 번만 다듬으므로 집 PC에 별도 Codex 로그인을 할 필요가 없습니다.
클라이언트의 ‘AI 로그인 확인’은 **그 기기의 로컬 AI 검사**이지 SB 서버 검사 버튼이 아닙니다.
Ask·선택 텍스트·번역 등의 고급 기능 전체를 원격 서버로 전달하는 것은 현재 범위와 다릅니다.

### 6. 이제 모든 처리가 바로 끝나나요?

**아직 수 초가 걸릴 수 있습니다.** 이번 수정은 연결 실패·잘못된 취소·헷갈리는 표시를 해결한 것이며,
AI 처리 시간을 0초로 만드는 업데이트는 아닙니다. 음성 인식 다음에 AI의 응답을 기다리는 시간이 남습니다.
현재 Codex 요청은 Fast를 사용하고, 간단한 받아쓰기는 Medium, 복잡한 작업은 High 정책을 적용합니다.
Fast는 속도 보장이 아니며 모든 스타일·앱에서 Typeless만큼 빠르다고 검증하지 않았습니다.
AI 다듬기를 끄면 해당 대기는 생략되지만, 문장 정리 품질도 달라집니다. [측정값과 한계](docs/VALIDATION.md).

## 설치 파일과 처음 설정

| 기기 | 릴리스 파일 | 설치 후 필요한 것 |
| --- | --- | --- |
| Windows x64 | `Ultra-STT-1.1.62-windows-x64-setup.exe` | 개인 서버 연결 또는 본인 STT·AI 설정 |
| Mac Apple Silicon | `Ultra-STT-1.1.62-macos-arm64.zip` | 압축 해제한 앱을 Applications에 설치, 마이크·접근성 허용, 개인 서버 연결 |
| Android | `Ultra-STT-1.1.62-android.9-debug.apk` | 기존 앱을 삭제하지 않고 업데이트. 새 기기만 마이크·접근성 허용 및 연결 설정 |

이번 [개인 프리뷰 2](https://github.com/toughCSB/ultra-stt/releases/tag/v1.1.62-personal.2)는 **Android·문서만 업데이트**합니다. Windows·Mac 파일은 이전 릴리스와 바이트 단위로 같습니다. Windows는 공인 코드 서명이 없어 SmartScreen 경고가 날 수 있고,
Mac은 개인 ad-hoc 서명이며 Apple notarization을 받은 앱이 아닙니다. Android는 개인 debug 서명 APK이고 Play Store 배포가 아닙니다.
자동 업데이트용 서명 패키지·`latest.json`은 제공하지 않으므로 릴리스 파일로 수동 설치합니다.
파일 무결성은 함께 제공하는 `SHA256SUMS.txt`로 확인할 수 있습니다.

집 PC `csb-home`에는 설치와 서버 인증 설정을 마쳤고, 사용자가 실제 음성→커서 입력 성공을 확인했습니다.
단축키를 눌러 시작하고 다시 눌러 종료합니다. **설정에 저장된 단축키가 기준**이며 기존 사용자 설정은 바꾸지 않습니다.
기존 키보드·개발 Codex 로그인은 그대로 두었고, 새 앱의 자동 시작은 끈 상태입니다.

이미 설정한 기기는 기존 연결 정보를 유지합니다. 다른 사람이 APK를 설치한다고
자동으로 이 개인 서버에 연결되거나 구독 로그인이 공유되지는 않습니다. iOS 네이티브 앱과 휴대폰 자체의 오프라인 모델은 아직 없습니다.

## 데스크톱 사용 순서

1. **설정**에서 음성 인식 제공자, 사용할 마이크와 출력 방식을 선택합니다.
2. AI 다듬기를 사용할지 정하고, **홈**이나 트레이에서 모드를 선택합니다.
3. 문장을 넣을 앱의 입력칸에 커서를 둡니다.
4. 받아쓰기 단축키로 녹음하고, 키를 놓거나 토글 단축키를 다시 눌러 완료합니다.
5. 실행창에서 녹음·전사·다듬기 상태를 확인합니다. 취소는 **Esc 키 또는 Esc 버튼**입니다.
6. 나중에 다시 사용할 문장은 **기록**에서 검색·복사합니다.

단축키는 변경할 수 있으며 기존 설치의 사용자 설정을 보존합니다. 소스의 초기 기본값은 다음과 같습니다.

| 작업 | Windows | macOS |
| --- | --- | --- |
| 받아쓰기 | `Ctrl+/` | `Fn` |
| Ask Anything | `Ctrl+.` | `Fn+Space` |
| 번역 | `Ctrl+Shift+/` | `Fn+LeftShift` |
| 진행 중 녹음·처리 취소 | `Esc` | `Esc` |

Windows 초기값은 누른 채 말하기, Mac은 토글입니다. 작업마다 최대 세 개의 단축키를 둘 수 있습니다. 실제 설치에서 바꾼 단축키는 기본값보다 우선하며, 스크린샷의 키 조합을 그대로 따라야 하는 것은 아닙니다.

## 다섯 가지 AI 다듬기

| 모드 | 어떻게 바꾸나요? | 어울리는 상황 |
| --- | --- | --- |
| **원문 · Original** | 명백한 오인식·오타·띄어쓰기와 무의미한 군더더기만 수정합니다. 단어·순서·말투·강조·기존 줄바꿈을 유지하고 자동 목록·문단 재구성을 하지 않습니다. | 말한 표현을 최대한 그대로 남기기 |
| **최소 · Minimal** | 표현과 순서는 최대한 유지하고 문장부호·자연스러운 문장 구분·명백한 군더더기를 정리합니다. | 가볍게 다듬는 일상 받아쓰기 |
| **깔끔하게 · Clean** | 사실·말투·정보량을 보존하면서 어순과 표현을 조금 정돈합니다. | 메시지·메모 |
| **구조화 · Structured** | 여러 항목을 목록으로 정리하고 필요할 때 짧은 주제 제목을 붙입니다. 새 사실은 추가하지 않습니다. | 할 일·회의 내용 |
| **전문적으로 · Professional** | 불필요한 인사말이나 과장 없이 간결한 업무 문장으로 정리합니다. | 이메일·보고 |

**원문도 AI 처리 모드입니다.** AI를 완전히 건너뛰려면 다듬기를 비활성화하세요. 선택 텍스트 편집·번역·씬·사용자 지침 등 명시적으로 다른 작업을 요청한 경우에는 해당 작업 규칙을 따릅니다.

### 모드 변경은 한 번의 선택으로

- **트레이:** 우클릭 → AI 다듬기 모드 → 원하는 모드.
- **홈:** 그림과 설명이 있는 다섯 버튼 중 하나를 클릭.
- **음성 실행창:** 모드 표시나 마이크 영역에서 선택 메뉴 열기.

초록색 강조와 체크 표시가 현재 선택입니다. 선택은 즉시 저장되고 다른 화면에도 동기화됩니다. 녹음 중 바꾸면 그 녹음이 끝날 때 적용되고, 이미 처리가 시작됐다면 다음 녹음에 적용됩니다.

### 홈의 막대 그래프는 무엇인가요?

**날짜별로 불러온 전사 기록 건수**입니다. 음량 표시나 장식이 아닙니다.

- 최근 14일의 날짜·건수를 보여 주며, 기록이 없는 날도 표시합니다.
- 막대를 클릭하면 해당 날짜의 기록 화면으로 이동합니다.
- 현재 불러온 **최대 200건**이 기준이며 전체 DB 통계인 것처럼 표시하지 않습니다.
- 마지막 처리 시간은 현재 실행 세션의 마지막 작업 기준입니다. 말한 시간은 포함하지 않습니다.
- Mac 원격 경로는 서버 STT와 AI를 합친 원격 처리 시간으로 표시합니다.

| 데이터 | SQLite 기록·사전, 로컬 설정, OS credential vault 연동 |
| 개인 STT | `faster-whisper 1.2.1` + `CTranslate2 4.8.1`, Whisper large-v3, CUDA float16, beam size 5, VAD |
| 개인 AI | `codex-cli`, ChatGPT 구독 로그인, `gpt-6-luna` |
| Fast | 이 Codex 어댑터의 모든 요청에서 `service_tier="priority"` 지정 |
| 추론 강도 | 단순·짧은 받아쓰기 Medium, 복잡한 작업·용어 보존이 중요한 작업 High |
| 원격 연결 | Tailscale Serve HTTPS, 동일 소유자 확인, 기존 Bearer 인증 |
| 설치·검증 대상 | Windows x64, macOS arm64 |
| 모바일 | Android 작은 음성 버튼·5색 모드·반원 드래그 선택, 기존 키보드 유지; 앱 테스트 입력창의 실제 음성→커서 성공 확인. 외부 편집기는 별도 검증. iOS는 브라우저 복사·공유 |

GPU 경로에는 CUDA를 사용할 수 있는 NVIDIA 환경과 별도 모델 다운로드가 필요합니다. 검증되지 않은 최소 VRAM·RAM 수치를 제시하지 않습니다. Apple Speech, Whisper 호환 서버, Deepgram, AssemblyAI, Aliyun Qwen3, Volcengine 등의 통합 코드도 있지만, 제공자별 인증·플랫폼 지원이 필요하며 모두 실사용 검증한 것은 아닙니다.

## 속도 최적화 원칙

품질을 낮추기 위해 작은 STT 모델로 바꾸거나 AI를 몰래 생략하지 않습니다.

1. **GPU 모델 예열·재사용:** 시작 때 준비하고 성공한 전사 뒤 모델을 유지합니다.
2. **불필요한 호출 제거:** HTTP 연결을 재사용하고, 서버가 다듬은 Mac 결과를 다시 AI에 보내지 않습니다.
3. **Codex 완전 분리:** 앱 전용 `CODEX_HOME`과 짧은 앱 전용 지침을 사용합니다. 개발용 설정·인증 파일을 복사하지 않습니다.
4. **Fast + 조건부 추론:** Original/Minimal/Clean의 1,024자 이하 일반 받아쓰기는 추가 컨텍스트가 없을 때 Medium입니다. 선택 텍스트·번역·씬·사용자 지침·사전·활성 교정 규칙이 있거나 복잡한 스타일이면 High를 유지합니다.
5. **취소 전파:** 실행창에서 취소하면 소유한 처리 작업을 종료하고, 원격 클라이언트 연결이 끊기면 서버 작업도 중단합니다.

**현재도 클라우드 AI 처리에는 수 초가 걸립니다.** Fast 지정이 일정한 지연을 보장하지 않으며 구독 사용량 제한도 그대로 적용됩니다. 입력 토큰 절약률과 구독 사용량 절약률은 같지 않습니다. Typeless 동급 속도는 입증하지 않았습니다. [실측·검증 범위](docs/VALIDATION.md)에 측정값과 한계를 함께 정리했습니다.

## 소스에서 실행·빌드

비공개 저장소에 접근할 수 있는 계정으로 복제합니다.

```sh
git clone https://github.com/toughCSB/ultra-stt.git
cd ultra-stt
npm ci
npm run tauri dev
```

### 개발 환경

- Node: 20.x 사용 시 **20.19 이상**, 또는 **22.12 이상**.
- Rust: stable **1.87 이상**.
- Windows: Visual Studio C++ Build Tools, WebView2.
- macOS: Xcode Command Line Tools.
- 개인 CUDA 서버: Python **3.11**, `local_stt/pyproject.toml`의 의존성, NVIDIA CUDA 환경과 Whisper 모델.

일반 앱 번들:

```sh
npm run tauri build
```

산출물은 `src-tauri/target/release/bundle/`에 생성됩니다. 저장소에는 모델·Python 가상환경·인증·개인 설정을 넣지 않습니다.

### 준비된 개인 환경에 설치

Windows helper는 부모 폴더의 기존 런타임·Cargo cache를 사용하는 도구입니다. 새 PC에서 모든 환경을 자동 준비하는 설치 명령은 아닙니다.

```powershell
powershell -NoProfile -File scripts/build-windows.ps1 -Install
```

Mac에서는 다음과 같이 빌드·설치합니다.

```sh
sh scripts/build-macos.sh --install
```

기존 앱은 교체 전 백업합니다. Mac은 `com.ultrastt.personal` 식별자의 안정적인 로컬 ad-hoc 서명을 사용하며 **Apple 공증을 받은 공개 배포판은 아닙니다**. 음성 캡처에는 마이크 권한, 커서 입력에는 손쉬운 사용 권한이 필요합니다.

### 앱 전용 Codex 로그인

Windows의 기존 공식 native CLI를 공유하되 로그인과 지침 폴더를 분리합니다.

```powershell
pwsh -NoProfile -File scripts/configure-codex-profile.ps1 -Login
pwsh -NoProfile -File scripts/configure-codex-profile.ps1 -Profile isolated
```

개발용 인증 파일을 복사하지 않고 앱 프로필에서 직접 로그인합니다. 현재 Mac 원격 구성은 Windows 서버의 AI를 사용하므로 Mac에서 두 번째 Codex 로그인을 할 필요가 없습니다.

세부 안내: [Windows 설치](docs/windows-personal.md) · [Mac 설치·권한](docs/macos-personal.md) · [Codex 분리](docs/codex-isolation-personal.md) · [원격 구성](remote/README.md).

## 개인정보·운영 경계

- 로컬 STT는 선택한 로컬 호스트에서 처리합니다. Mac 원격 모드의 음성은 비공개 Tailnet을 통해 Windows 서버로 전송됩니다.
- Codex 다듬기를 켜면 인식한 텍스트와 작성 지침은 설정한 ChatGPT 서비스로 전송됩니다. 완전 오프라인 AI인 것처럼 설명하지 않습니다.
- 선택 텍스트는 이를 사용하는 작업에서만 컨텍스트로 포함합니다. 앱 분류는 로컬에서 하며 원본 창 제목을 앱 컨텍스트로 보내지 않습니다.
- 사용 가능한 OS 보안 저장소를 이용합니다. 보안 저장소 실패 시의 기존 fallback은 플랫폼 안내에 설명되어 있으므로, 모든 설정 파일이 비밀정보 없는 파일이라고 가정하지 마세요.
- `.env`, 모델, 인증 파일, 개인 DB·런타임·로그는 Git에 넣지 않습니다.
- Ultra STT 자체의 관리형 구독·포함 API 할당량은 없습니다. 기반 프로젝트의 cloud 연동은 이 개인 배포 구성과 별개입니다.
- 원격 연결은 **Serve**이며 인터넷 공개용 **Funnel**을 사용하지 않습니다. 서버가 켜져 있고 Tailnet에 연결돼 있어야 합니다.

## 검증 상태와 남은 개발

1.1.62 기준 프런트엔드 **414개**, Windows native **629개**, Mac native **635개** 테스트가 통과했습니다. 기본 native 실행에서는 외부 인증·제공자에 의존하는 live 테스트 세 개씩을 제외합니다. 두 데스크톱 대상의 실제 빌드·설치도 완료했습니다.

Mac → Windows 원격 요청에서 다섯 모드, AI 비활성화, 기존 헤더 없는 요청, 잘못된 헤더, 인증 없는 요청과 클라이언트 취소를 확인했습니다. 최신 Mac의 실제 마이크 → 커서 입력 → Esc 사용 확인은 별도 수동 확인 항목입니다. 테스트 통과를 물리적 키 입력 검증으로 대신하지 않습니다.

**Android .9는 빌드·80개 Java 검사·Lint·서명, 실기기 18개 시나리오와 ChatGPT/Grok 위젯 진입 각각 5회를 통과했습니다.** 이전 .5의 통신 10개 검사와 실제 한국어 음성→커서 사용자 확인도 있지만, 이를 최신 .9의 새 실발화 검증으로 바꿔 말하지 않습니다. 모든 외부 편집기 호환성을 보장하지 않습니다. 집 PC의 절전 후 단축키 무반응 보고는 관찰 중이며, 요청에 따라 이번 릴리스에 복구 기능이나 추가 설치를 넣지 않았습니다. iOS 네이티브 앱은 미구현입니다.
